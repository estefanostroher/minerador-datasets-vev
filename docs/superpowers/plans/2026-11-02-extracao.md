# Extração estática concorrente — plano de implementação

> **For agentic workers:** usar superpowers:subagent-driven-development com implementação delimitada, revisão de aderência e depois qualidade. Checkout atual, branch feature/minerator-pilot; sem worktrees, branches auxiliares ou commits automáticos.

**Goal:** Extrair funções/métodos, documentação original e testes diretamente associados dos aprovados da triagem para um único JSONL.

**Architecture:** Python recupera snapshots imutáveis com PyGithub e coordena WorkerPool/RateLimitGate. Cada worker envia fontes em memória para um auxiliar Node.js com TypeScript Compiler API e devolve um grupo ordenado de registros; somente o coordenador escreve.

**Tech Stack:** Python >=3.11, PyGithub existente, Node.js >=22, TypeScript com versão fixada e npm lockfile; pytest e node:test apenas para riscos concretos.

## Interface entre Python e Node

Auxiliar em `src/robo_minerador/typescript/analyze.mjs`, dependência npm instalada nesse diretório. Um objeto JSON via stdin e um JSON via stdout; stderr somente diagnóstico sanitizado. Entrada:

```json
{"files":[{"path":"src/a.ts","content":"export function a(x: number) { return x + 1; }"}],"issues":[]}
```

Resposta: `analyzer` com name/version, `instances` com os campos da especificação (sem IDs de repositório/instance_id), `local_dependencies` como from/specifier/resolved_path, `unresolved_references` e `issues` com code/message/path quando aplicável. Python acrescenta origem/identificador/instante e calcula hashes dos arquivos. O auxiliar deve exportar analyze(input) para testes sem iniciar CLI no import. Erros de protocolo e timeout tornam o repositório pendente, nunca rejeitado cientificamente.

Limites iniciais: os existentes do Snapshot (20 mil entradas, 512 leituras, 1 MiB/arquivo, 8 MiB acumulados); subprocesso com timeout de 180 segundos e heap de 512 MiB. Limitações devem estar nas evidências e documentação. Reutilizar arquivos já lidos em memória. Arquivos não elegíveis para texto podem ser listados como contexto indisponível; não substituir bytes por texto inventado.
